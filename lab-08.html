Concepts

6 ideas, defined where you need them

Each one gets three sentences in the notebook: what it is, what it can't tell you, and an anchor from this lab.

  • 📘
    Hard gateA count of must-never events (here, red-line violations on an adversarial suite) with a bar of 0, checked before and apart from any score.
  • 📘
    pass^kThe probability that all k isolated trials of a task succeed, averaged over tasks. For a task with c passes in n trials the unbiased estimate is C(c, k) / C(n, k) (Lab 06b): the chance that k of its n trials, drawn at random, all passed.
  • 📘
    A/A testRun a detector on a system compared with itself (same build, rerun on the same items). Nothing changed, so every alarm is false.
  • 📘
    Paired comparisonBoth versions run on the same items. Per item, d = v2.1 − v2.0 is +1 (fixed), −1 (broken) or 0, so item difficulty cancels and only the flipped items carry information.
  • 📘
    Model drift vs. mix shiftA blended rate is Σ (segment share × segment rate). Model drift changes a segment's own rate; a mix shift changes the shares while every rate holds still.
  • 📘
    Minimum detectable effect (MDE)The smallest true change an eval of size n catches with 80% power at 95% confidence: MDE ≈ 2.8 · √(Var / n), Task 7's power formula solved for δ.

Words you’ll meet

Jargon decoder

The notebook defines each term right before you need it. Here’s the cheat sheet.

Slice
100 graded test items that probe one scenario (e.g. multi-hop questions)
Pass rate
Share of items that passed a binary check
Incumbent
The version serving customers now (v2.0)
Golden set
A small, fixed, hand-checked set of prompts with known right answers
Red line / hard gate
A behavior that must never happen, gated on a count with a bar of 0
RL-1 / RL-2 / RL-3
LegalBot's red lines: definitive legal advice to a non-lawyer, another client's data, a fabricated citation
Weighted quality score
Metric averages combined with weights; good for "better by degree"
Soft gate (WARN)
A failed check that forces a human review instead of blocking
CI / pre-production
Checks on every pull request / the thorough run on each release candidate
Shadow / canary
The candidate answers a hidden copy of real traffic / serves x% of real users
Online evaluation
An LLM judge scoring a sample of live production traces
Trial
One isolated end-to-end run of a task
All 40 terms in this lab
pass@1 / pass^k
Per-trial success rate / probability that all k trials succeed
Regression vs. capability suite
Tasks that must keep working (near 100%) / hard tasks you're improving on (low rates expected)
Graduation
Moving a reliably solved capability task into the regression suite
A/A test
Running a detector on a system against itself; every alarm is false
Flaky item
An item whose verdict can flip on a rerun with nothing changed
Standard error (SE)
The typical size of the random error in an estimate; shrinks like 1/√n
95% CI
The range of true values the data can't rule out; if it contains 0, "no change" isn't ruled out
Wilson interval
A CI for a pass rate that stays inside [0, 1] and still works at 0/n
Rule of three
0 failures in n ⇒ the true failure rate is plausibly up to ≈ 3/n
Paired comparison
Both versions run on the same items, compared item by item
p-value / α
Chance of a result this extreme if nothing changed / the cutoff (0.05) for "significant"
McNemar test
Exact paired test: is the split of fixed vs. broken items more lopsided than coin flips?
Holm correction
Adjusts p-values so 30 tests together keep a 5% chance of any false alarm
Power / MDE
Chance of catching a real effect of a given size / the smallest effect your n can catch
Bootstrap
Resample units with replacement many times to get a CI without a formula
Segment / traffic mix
A group of live traffic (e.g. multi-doc questions) / each segment's share of traffic
Model drift vs. mix shift
A segment's own rate changes / only the segment shares change
Non-inferiority
"No worse than the incumbent by more than a margin, with 95% confidence"
p50 / p95 latency
Median time / the time 95% of requests finish within (your slowest 1 in 20)
Cost per successful task
Total spend ÷ number of successful runs
MSA / indemnification
Master services agreement, the umbrella contract / a clause where one party covers the other's losses
Circular 230
US Treasury rules governing tax professionals who practise before the IRS
W-2 / 1099-NEC
US forms reporting wages from an employer / payments to an independent contractor
Raw agreement
Share of answers where a judge and a human agree; dominated by the common class
TPR / TNR
Of the answers that truly failed, the share the judge flags / of those that truly passed, the share it passes
Youden's J
TPR + TNR − 1: the share of a true difference that survives the judge (1 = all of it, 0 = none)
Break-even mix
The segment share at which two versions tie on a blended metric
Schedule C
The US form a sole proprietor uses to report business income and expenses
