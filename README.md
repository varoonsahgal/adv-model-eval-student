# Advanced AI Model Evaluation · Labs

**Start here: <https://varoonsahgal.github.io/adv-model-eval-student/>**

Fifteen hands-on Colab labs on evaluating LLM systems: traces, failure analysis, structured outputs, RAG, LLM judges, statistics, agents, multi-turn assistants, safety, and an end-to-end launch pipeline. Every lab runs offline in Google Colab with no API keys.

## Run a lab

1. Open the [Lab Hub](https://varoonsahgal.github.io/adv-model-eval-student/) and click **Open in Colab** on any lab.
2. **File → Save a copy in Drive** so your edits are yours.
3. **Runtime → Run all.**
