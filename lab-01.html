Words you’ll meet

Jargon decoder

The notebook defines each term right before you need it. Here’s the cheat sheet.

Trace
The full record of one request: every step, with timings, inputs and outputs, arranged as a tree
Observation
One step inside a trace (an LLM call, a search, a tool call): start/end time, input, output, and a pointer to its parent
Span
OpenTelemetry's word for any step. Langfuse uses it only for the generic step type
Root observation
The outermost step. It stands for the whole request: its input, output and latency are the trace's
Generation
An observation for one LLM call. The only type that carries model, tokens and cost
Agent · tool
An agent is an LLM-driven program that decides which steps to run; a tool is a function it calls (here, a plan lookup)
Retriever · RAG
The retriever searches a document index for passages that match the question. RAG (retrieval-augmented generation) = the LLM answers from what was retrieved
Vector search · similarity
Ranking documents by how close their embeddings (numeric fingerprints of meaning) are to the question's; similarity is that closeness, 0 to 1
Token
The unit models read, write and bill by: a word fragment, roughly 4 characters of English
Input vs output tokens
Tokens you send (instructions, context, history) vs tokens the model writes. Output costs 5× more on gpt-6-luna
Cost · cost_details
Dollars per call = tokens × list price per million. The lab sends it explicitly with each generation
Latency
Time from a step's start to its end. The root's latency is what the user waits
All 36 terms in this lab
Percentile (p50, p95, p99)
Sort requests by latency. p50 (the median) is the middle one; p95 is the one 95% are at or below, i.e. what your slowest 1 in 20 users get
Mean
The arithmetic average. One slow outlier moves it; the median barely moves
SLA
Service-level agreement: the promised response time (here 1.5 s per answer)
Timeout · retry
A call abandoned after a time limit · a second attempt. Both add to the user's wait and hide behind a fluent answer
Session · tags · metadata
A group of traces (here, one notebook run) · filterable labels · key-value notes on a trace
Flush · ingestion delay
Send buffered trace data now · the seconds before written data can be read back
Pagination · cursor
APIs return results in pages; the cursor says where the next page starts
Score
One evaluation result attached to a trace or to one step: numeric, boolean or categorical
Evaluator
Whatever produced a score: a rule (code), an LLM judge, or a human
Rubric
Written instructions for what each score value means. It is what makes grading repeatable
Deterministic
Same input, same output, every time. Rules are; LLM calls are not
Regex
A text-pattern rule, e.g. "the answer ends with ?". Cheap and brittle
LLM judge
An LLM that applies your rubric to an answer and returns a score
Calibration
Measuring an evaluator against trusted (human) labels before you trust its numbers
TPR · TNR · Cohen's κ
Of the items humans called positive, the share the judge also caught · the same for negatives · agreement after removing what chance alone would produce
Ground truth · reference answer
The known-correct label or answer you compare against. Rare in production
Reference-free check
An evaluator that needs no correct answer (e.g. "is every retrieved doc current?"), so it can run on all traffic
Faithfulness vs correctness
Faithful: the answer sticks to the context it was given. Correct: it is true. A stale document produces faithful-but-wrong
Slice
A subset of requests that share a label (here, intent: limits, account, …)
Confidence interval (Wilson)
The range the true rate plausibly sits in, given n observations. Wilson's version stays sensible when n is small
CI (two meanings)
"95% CI" = confidence interval. "Gates in CI" = continuous integration, the checks that run on every code change
Gate
A check that must pass no matter how good the other scores are; failing it blocks the release
OpenTelemetry (OTel) · gen_ai.*
The open, vendor-neutral standard for traces, metrics and logs · its agreed names for LLM steps (chat, invoke_agent, execute_tool, retrieval), still Development status
Mock provider · local mode
Simulated LLM answers (no key) · an in-memory stand-in for Langfuse. Together they make Run All offline and identical for everyone
