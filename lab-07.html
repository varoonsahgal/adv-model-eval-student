Words you’ll meet

Jargon decoder

The notebook defines each term right before you need it. Here’s the cheat sheet.

Robustness
The bot makes the same decision when the input changes in ways that shouldn't matter (a typo, spacing, a rephrase)
Perturbation
A controlled edit to an input: whitespace, typos, paraphrase, or an added conflicting instruction
Token
The word piece a model actually reads; extra spaces or typos change the tokens
Drift
How far a perturbed response moved from the original response
Character similarity (SequenceMatcher)
Python's built-in text-overlap score, 2 × matching characters ÷ total characters, from 0 to 1
Consistency rate
Share of perturbed responses still "stable" (similarity ≥ 0.85)
Random seed
The starting number of a random generator: same seed, same "random" typos
n
The number of test cases behind a rate. Small n means wide uncertainty
Wilson interval
A 95% confidence interval for a proportion that stays honest at small n and at 0% or 100%
Crosstab
A count table: one variable down the rows, another across the columns
Guardrail / guard
A check that runs beside the model and blocks risky inputs or outputs
Keyword guard / blocklist
A guard that blocks when a fixed phrase appears ("personal email"); it matches strings, not meaning
All 46 terms in this lab
Prompt injection
Text that tries to override the bot's instructions: direct if the user types it, indirect if it hides in content the model reads
Jailbreak
A prompt crafted to talk a model past its rules, e.g. the "DAN" (Do Anything Now) role-play
Red teaming
Attacking your own system on purpose, before someone else does
PII
Personally identifiable information: emails, home addresses, SSNs, card numbers
SSN
US Social Security number; it doubles as an individual's taxpayer ID, so a leak is a serious incident
System prompt
The hidden instructions the operator gives the model (see SUPPORT_SYSTEM_PROMPT in the config cell)
OWASP
Open Worldwide Application Security Project: a nonprofit whose "Top 10" lists name the most common security risks
LLM01–LLM10
OWASP's 2025 IDs for LLM-app risks, e.g. LLM02 Sensitive Information Disclosure, LLM06 Excessive Agency (the bot acts beyond its authority), LLM10 Unbounded Consumption (running up cost or load)
ASI01
OWASP Agentic 2026: Agent Goal Hijack, an agent steered by instructions hidden in data it reads
NIST AI 600-1
The Generative AI risk profile from NIST (the US National Institute of Standards and Technology): 12 named risks
Confabulation
NIST's term for confidently stated false or fabricated content (it avoids "hallucination")
Taxonomy tag
A shared risk ID attached to each test, so results can be reported per risk
Regex
A regular expression: a text-matching pattern such as \bssn\b (the word ssn, not inside another word)
Defense in depth
Stacking independent checks so one layer's miss is another's catch
False positive
Flagging or blocking something that was actually fine
Threshold (t)
The score at which a guard starts blocking; a lower t blocks more of everything
Recall
Of the harmful prompts, the share the guard blocked
Precision
Of the prompts the guard blocked, the share that were really harmful
Harmful pass-through
Harmful prompts allowed ÷ all harmful prompts (1 − recall). Lower is safer
Over-refusal
Benign prompts blocked ÷ all benign prompts (the false-positive rate). Lower is more helpful
Benign-but-scary
A legitimate request that uses attack-like words ("my account was hacked, how do I lock it?")
Frontier / operating point
The trade-off curve between the two errors as the threshold moves / the point you actually deploy
Spearman correlation
A rank correlation from −1 to 1; 1 means "higher on one ranking ⇒ always higher on the other"
Prevalence (base rate)
The share of real traffic that is harmful. It changes precision, not recall
p50 / p95 latency
The time within which 50% / 95% of calls finish; p95 is what users feel
Preprint (arXiv)
A paper posted publicly before peer review
ASR
Attack success rate: successful attacks ÷ attacks tried
Static vs adaptive attack
A fixed list written in advance vs an attacker who watches what gets blocked and rewrites
Black-box attack
The attacker sees only the guard's allow/block decision, never its code or scores
StrongREJECT
A 2024 jailbreak benchmark whose grader scores harm (refused? specific? convincing?), not refusal words
Scope violation
Advice the bot isn't allowed to give, such as individualized tax advice ("you should claim…")
Hard gate
A pass/fail limit no average can offset (e.g. safety failures must be 0)
ICLR · ICML · NeurIPS
The main peer-reviewed machine-learning conferences, cited on research cards
CFPB · IRS OPR
The US Consumer Financial Protection Bureau · the IRS Office of Professional Responsibility (oversees tax practitioners)
