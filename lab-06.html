Words you’ll meet

Jargon decoder

The notebook defines each term right before you need it. Here’s the cheat sheet.

Agent
a model in a loop: plan, call a tool, read the result, repeat until it answers
Tool call · tool result
the function the agent invokes, with the arguments it chose · what that function returns
Read vs write tool · side effect
read tools look things up; write tools change the world, and that change (a booking now exists) is the side effect
Trajectory (also trace, transcript)
the ordered record of one run: tool calls, results, final answer
Chain-of-thought
the model's private reasoning text; this lab grades observable actions instead
Required / forbidden action · dependency · invariant
must happen / must not happen · allowed only after another action · a rule every acceptable path obeys
End state (outcome)
what is actually true in the systems after the run, e.g. which bookings exist
Precision · recall · F1
of the tools used, the share that were needed · of the tools needed, the share used · their harmonic mean (high only if both are)
Schema vs semantic validation
right fields, types and formats vs values that make business sense (check-out after check-in)
JSON Schema · ISO date
a standard declaration of the fields and types a JSON object must have · the YYYY-MM-DD date format
Do-nothing (no-op) agent
a fake agent that calls no tools and says nothing; a sanity check for graders
Vacuous pass
a grader passing a run for the wrong reason, e.g. because nothing happened
All 41 terms in this lab
Diagnostic score
an average of quality signals, used to rank and debug runs, not to decide
Hard gate · critical failure
a rule that blocks release on its own · a failure that trips it (an unrequested booking)
Compensatory score
one where strength elsewhere can buy back a zero; averages are compensatory, gates are not
Path vs outcome · lucky pass
how the agent got there vs where it ended up · the right end state reached by breaking an invariant
Trajectory match modes
strict, unordered, superset, subset: ways to compare an agent's tool list with a reference list
agentevals · LangSmith
LangChain's open-source agent-eval library · its hosted tracing and eval platform
False alarm · miss
a grader rejecting an acceptable run · accepting an unsafe one
Calibration set
runs an expert has labeled, kept to measure how often a grader agrees
Confusion matrix
a table counting each (expert label, grader label) pair; the diagonal is agreement
TPR · TNR
true-positive rate: share of real failures the grader catches · true-negative rate: share of good runs it clears
Cohen's κ (kappa)
agreement corrected for chance: 1 = perfect, 0 = no better than guessing
LLM judge · rubric
a model prompted to grade outputs · the explicit pass condition for each criterion it checks
Verbosity / position bias
a judge favoring longer answers / whichever answer it reads first
Structured outputs
an API mode that forces the model's reply to match a JSON schema you supply
Nondeterministic
the same input can produce a different run each time
pass@k · pass^k
at least one of k trials succeeds · all k trials succeed
95% CI · Wilson interval · rule of three
the range of true rates consistent with the data · a CI formula that behaves at small n · zero failures in n runs bounds the rate at about 3/n
Reward hacking
passing the grader without doing the task it stands for
Baseline · candidate · regression
the version in production · the version you want to ship · something that used to work and now doesn't
p95 latency
the time within which 95% of runs finish; shows the slow tail an average hides
Span · OpenTelemetry (OTel) GenAI conventions
one unit of work inside a trace (a model call, a tool call) · the open standard for naming those spans
Langfuse
an open-source LLM tracing and evaluation platform; it calls spans observations
First point of divergence
the earliest span where the run departs from correct behavior
Canonical call
tool name plus arguments serialized as sorted JSON, so identical calls compare equal
Productive retry · exact repeat · cycle
same tool with corrected inputs · the identical call again · A→B→A→B
Evaluation flywheel
every production failure becomes a permanent regression case
Fingerprint (hash)
a short code computed from the dataset's contents; any change produces a new one
Benchmarks in the research cards
τ-bench (TAU-bench): customer-service agents with simulated users · CORE-Bench: agents reproducing published research code · ImpossibleBench: coding tasks whose tests contradict the spec · Who&When, MAST: datasets of multi-agent failures · o3-mini: a 2025 OpenAI model
Promptfoo · Inspect AI · DeepEval · Braintrust
current eval frameworks and platforms (alternatives to the retired OpenAI Evals)
